## Cómo está hecha la página
- `index.html`: contiene el texto, las imágenes, las secciones y el formulario.
- `styles.css`: contiene colores, tamaños, tarjetas, Flexbox, Grid y Media Queries.
- `script.js`: calcula importes, valida campos y prepara el mensaje de WhatsApp.
- `img/`: contiene los recursos gráficos.

## Qué hace cada tecnología
HTML estructura la página. CSS decide cómo se ve. JavaScript responde a las acciones de quien la visita.

## Flujo del pedido
Ver productos → elegir variedad → indicar kilos → calcular importe → completar datos → abrir WhatsApp → confirmar con el negocio.

## Cómo estudiar un cambio
Primero buscá el elemento en HTML, después su clase o id en CSS, y por último la función que lo usa en JavaScript. Probá modificar un dato a la vez y observá qué cambia.
